# binfut-platform-restore

Исследовательская платформа для поиска торгового преимущества (edge) на
минутных данных фьючерсов Binance USDT-M (BTCUSDT, ETHUSDT).

## Принципы работы

1. **Pre-registration:** критерии PROMOTE / REJECT фиксируются в документе
   ДО просмотра тестовых данных. Вердикт, вынесенный по зарегистрированным
   критериям, пересмотру не подлежит.
2. **Отрицательный результат — валидный результат.** Все эксперименты
   (включая отклонённые) фиксируются в Журнале.
3. Данные — только из официальных публичных архивов Binance
   (data.binance.vision); тестовые периоды не просматриваются до прогона.
4. Решения о торговых правилах и порогах — только владелец.

## Структура

- `docs/` — Журнал (JOURNAL_*.md), протоколы экспериментов, инструкции
- `scripts/` — скрипты прогонов экспериментов
- `data/` — рыночные данные (в git не хранятся, скачиваются из архивов)

## Статус экспериментов

| ID | Гипотеза | Вердикт |
|---|---|---|
| E010 | signal edge (срез 2023-01..02) | **REJECT** — нет обобщения, издержки съедают |
| E011 | кросс mean-реверсия ETH→BTC | **REJECT** — эффект реален, но слаб; экономика отрицательна |

См. `docs/JOURNAL_2026-11-01.md` (полная история с метриками).

## Воспроизведение

```bash
python3 scripts/check_fresh_cross_signal.py   # проверка знака на свежей неделе
python3 scripts/e011_run.py                   # прогон E011 на holdout 2025-07..12
```

Данные предварительно скачать из `data.binance.vision`
(klines 1m, daily/monthly archives) в `data/raw/`.
