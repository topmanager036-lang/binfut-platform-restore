# E012 — PRE-REGISTRATION (зарегистрировано ДО просмотра holdout-данных)

Дата регистрации: 2026-11-02 (UTC+3). Статус: выполняется autonomously по
рекомендации из docs/E012_CANDIDATES.md (решение владельца о корзине альтов
может стать отдельной регистрацией E013).

## 1. Гипотеза

Тайм-серия моментум (TSMOM) на 1h: направление позиции = знак кумулятивной
доходности за K часов; размер = вол-таргет 30% годовых. На dev (2021-01..2025-12)
обе конфигурации положительны после издержек на обоих символах; короткий
горизонт (K=24ч) отрицателен (согласуется с E010/E011: минутные/короткие
горизонты реверсируют и не переживают издержек).

## 2. Формулы (замораживаются)

- r_t = ln(C_t / C_{t-1}) — часовые close Binance futures UM.
- Сигнал: M_t = ln(C_t / C_{t-K}); направление D_t = sign(M_t).
- Волатильность: vol_t = std(r, 720ч) × sqrt(8760) — годовая, окно 30 суток.
- Позиция: P_t = D_t × min(0.30 / vol_t, 3.0); vol_t = NaN → P_t = 0.
- Лаг: позиция P_t действует на доходность r_{t+1} (вход по закрытию след. бара).
- Издержки: cost_t = |P_t − P_{t−1}| × 4.5/2 / 10^4 (RT maker 4.5 bps).
  Стресс-отчёт (не решение): RT taker 15 bps.
- Часы с разрывом данных (шаг индекса > 1ч): r_t исключается из P&L
  (2026-10-28 не опубликован биржей — известный пропуск, зафиксирован здесь).

## 3. Рукава

- Вторичный (только отчёт): K = 72ч.
- Каждый рукав: портфель 50/50 BTC+ETH (простое средневзвешивание P&L двух
  символов), а также по-символьная разбивка.

## 5. Критерии вердикта (на holdout, первичный рукав K=720, портфель)

1. **Net Sharpe ≥ 0.5** (годовой: mean/std часовых net-доходностей × sqrt(8760));
2. **Net доходность > 0 на КАЖДОМ символе** (за весь период);
3. **Max Drawdown портфеля ≤ 50%** (по кумулятивному equity из часовых net).

**Все три выполнены → E012 = PROMOTE. Хотя бы один нет → REJECT.**
Вторичный рукав K=72 оценивается теми же критериями, но в вердикт не входит
(отчёт). После первого прогона правки запрещены; повторные прогоны holdout
не допускаются.
