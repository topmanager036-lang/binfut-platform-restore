## Предлагаемая регистрация E012 (текст — после выбора владельцем)

- **Данные:** 1h бары BTCUSDT+ETHUSDT; dev 2021-01..2025-12 (просмотрен),
  **holdout 2026-01..10** (скачивается только после утверждения).
- **Стратегия:** позиция = sign(ln(C/C_K)) × (0.30/vol30d), clip ≤ 3;

- **Исполнение:** вход по закрытию следующего 1h бара; издержки RT maker
  4.5 bps на смену стороны; taker 15 bps — стресс-отчёт.

  1. net Sharpe ≥ 0.5;

  3. maxDD ≤ 50%.
  Все три → PROMOTE; иначе REJECT. Рукава оцениваются раздельно.
- **Seed/детерминизм:** не требуется (без стохастики); версия данных —
  SHA256 манифестов zip-архивов в Журнале.
