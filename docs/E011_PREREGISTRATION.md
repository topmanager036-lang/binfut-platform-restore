# E011 — PRE-REGISTRATION (зарегистрировано ДО просмотра holdout-данных)

Дата регистрации: 2026-11-01, автор: ассистент, статус: утверждается владельцем.
После запуска прогона параметры замораживаются; правки возможны только до запуска.

## 1. Гипотеза

Кросс mean-реверсия: если за последние W минут ETH **отстал** от BTC
(кумулятивная разница лог-доходностей положительна), будущая доходность ETH
в среднем **выше** (ETH догоняет). И наоборот.

Мотивация (просмотренные периоды, НЕ используются для вердикта):
- исторический срез 2023-01..02 (E010): IC растёт с горизонтом;
- свежая неделя 2026-10-25..31: 12/12 комбинаций W×H положительны, 6/6 дней.

## 2. Формулы (фиксируются точно)

- r_x(t) = ln(C_x(t) / C_x(t−1)), x ∈ {BTCUSDT, ETHUSDT}, минутные close
  Binance futures UM (data.binance.vision).
- Сигнал: S_t(W) = Σ_{i=0..W−1} [r_btc(t−i) − r_eth(t−i)]
- Цель: fwd_h(t) = Σ_{j=1..h} r_eth(t+j)
- Метрика: IC = коэффициент Спирмена между S_t(W) и fwd_h(t) по всем минутам.

## 3. Конфигурации

- **Основная (для решения): W = 120, h = 60.**
- Чувствительность (только отчёт, не влияет на решение):
  W ∈ {30, 60, 120}, h ∈ {15, 30, 60, 120}.

## 4. Данные

- Dev (просмотрено, мотивация): 2023-01..02, 2026-10-25..31.
- **Holdout (вердикт, НЕ просматривался): 2025-07-01 .. 2025-12-31** (6 мес).
  Один прогон, без подглядываний и перезапусков.
- Контроль качества: inner join по минутам, длина 6×~43200 (± часы обслуживания).

## 5. Критерии решения (заданы ДО данных)

На holdout, основная конфигурация W=120, h=60:
1. IC ≥ +0.03 и p < 0.01 (Спирмен, все минуты периода);
2. устойчивость: ≥ 60% недель периода с IC > 0 (понедельная разбивка);
3. экономика (вторичный фильтр): упрощённая симуляция «позиция = знак S_t»,
   исполнение по close следующей минуты, round-trip издержки maker 4.5 bps
   на каждую смену позиции → net > 0 за период.

**Все три выполнены → PROMOTE** (кандидат на разработку стратегии).
**Хотя бы одно нет → REJECT.** Третьего исхода нет.

Урок E010 учтён: издержки taker RT ~15 bps как стресс-вариант отчёта.
