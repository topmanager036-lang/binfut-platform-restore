механика подтверждена: ~256 ребалансов за 5 лет при R=168. Ниже только

## Честное чтение скрина

1. Скорость за счёт горизонта — тупик (K=24 отрицателен везде). Скорость
   достигается волтаргетом на подтверждённом edge, а не частотой сделок.
2. Альты в TSMOM слабее BTC/ETH (корзина S+0.75..0.88 против core 1.21):
   добавление альтов в core НЕ повышает Sharpe (1.10 < 1.21).
3. XS-моментум — реальное новое семейство: Sharpe ~1.06–1.15, низкий
   гросс, слабость в медвежьем 2022 (−12%). Пригоден как диверсифицирующий
   рукав, не как одиночная стратегия.
4. Отбор K=168 для альтового рукава сделан по скрину (multiple testing) —
   именно поэтому holdout 2026 вынесет вердикт; соседи по сетке (72: 0.64,
   360: 0.78, 720: 0.75) тоже положительны — сетка гладкая, не остроконечная.
