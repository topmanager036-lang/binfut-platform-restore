# Как создать наш GitHub-репозиторий (один раз, ~5 минут)

Способ через браузер, командная строка не нужна.

## Шаг 1. Создайте пустой репозиторий

1. Зайдите на **github.com** под своим аккаунтом (если аккаунта нет —
   зарегистрируйтесь, это бесплатно).
2. Нажмите зелёную кнопку **New** (или «+» вверху справа → New repository).
3. Заполните:
   - Repository name: `binfut-platform-restore`
   - Выберите **Private** (закрытый, только для нас)
4. Ничего больше не отмечайте (никаких README, .gitignore, лицензий).
5. Нажмите **Create repository**.

## Шаг 2. Загрузите наши файлы

1. Скачайте из чата свежий архив **binfut-bundle-…-v2.zip** и распакуйте его
   на компьютере (появится папка с файлами: docs, scripts и др.).
2. На открывшейся после создания странице GitHub нажмите ссылку
   **uploading an existing file**.
3. Перетащите в окно браузера **папки и файлы из распакованного архива**
   (docs, scripts — папку data загружать не нужно, это рыночные данные,
   они публичные и качаются заново).
4. Внизу нажмите **Commit changes**.

Готово — репозиторий создан, копия нашей работы в безопасности.

## Шаг 3. Скажите мне

Напишите в чат: «GitHub готов» + скопируйте адрес репозитория
(что-то вроде `https://github.com/ваш-логин/binfut-platform-restore`).

## Что это даёт

- Код и документы больше никогда не потеряются при смене чата.
- Будет видна вся история изменений.
- Я буду говорить вам, какие файлы обновить после каждого блока работ
  (те же 2 клика: upload → commit).

## Если удобнее через программу

Если на компьютере стоит GitHub Desktop — можно клонировать репозиторий
и просто копировать в него файлы из архива, затем нажать Commit & Push.
Результат тот же.
