# GitHub-репозиторий: настройка и автоматизация

> Репозиторий создан: `github.com/topmanager036-lang/binfut-platform-restore`
> Первая загрузка выполнена. Ниже — режим АВТОМАТИЗАЦИИ.

## Режим автоматизации: один ключ на 90 дней (рекомендуется)

Чтобы владелец больше НЕ сохранял архивы вручную после каждого блока работ:

1. github.com → аватарка → **Settings** → **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. Название любое (например `binfut-auto`); **Expiration: 90 days**
3. Repository access: **Only select repositories** → binfut-platform-restore
4. Permissions → Repository permissions → **Contents: Read and write**
5. **Generate token** → скопировать → вставить в чат ОДИН раз

После этого:
- я сам выгружаю все результаты в GitHub после каждого блока работ;
- архив в Cloud — только как запасная копия: достаточно раз в день или когда
  я пишу «готовимся к новому чату»;
- в новом чате достаточно вставить свежий ключ (я скачу всё с GitHub сам)
  или приложить последний архив.

Безопасность: ключ открывает ТОЛЬКО этот репозиторий и ничего больше;
отзывается в один клик (Delete в списке токенов).

## (Опционально) Публичный репозиторий — полная автоматизация

Settings репозитория → внизу Danger Zone → **Change visibility** → Public.
В репозитории нет секретов (рыночные данные публичны и в git не входят).
Тогда в новом чате я восстанавливаю всё сам, без ключей и архивов —
ноль действий от владельца. Решение за владельцем.

## Если удобнее через программу

GitHub Desktop: клонировать репозиторий, копировать в него файлы,
Commit & Push. Результат тот же — но с ключом выше это не нужно.
